## Présentation

API REST de catalogue de livres : création, consultation et gestion des ouvrages, avec téléversement des couvertures.

**Pourquoi ce choix.** Un catalogue se manipule par une API stable, que plusieurs interfaces peuvent ensuite consommer.

---

## Ce que fait le projet

- Modèle de données Mongoose
- **Téléversement des couvertures** via `multer`, servies en statique
- CORS activé pour la consommation depuis une application tierce
